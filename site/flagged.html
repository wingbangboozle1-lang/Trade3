How to review this

  1. Pick any row on any page. Its last cell is a source ID; the Sources page turns that ID into an official URL.
  2. Open the URL and search the page for the exact field name or number in the row.
  3. If the source does not support the row, add it here and open an issue. The build does not prevent a wrong claim — it prevents an unsourced claim — so human review is still the last line of defence.
