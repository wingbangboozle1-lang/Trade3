This site is documentation, not live market data. It publishes verified API contracts, the fee model, requirements, findings and flagged items. The live dashboard itself runs as an app (app/); it is not hosted here because a static page cannot hold a private key or keep a WebSocket session open. See what could not be verified.

Kalshi demo: live event tracking, $0.10 swing alerts, and a simulated trading tournament

This project tracks the highest dollar-volume live events on Kalshi's demo environment inside five topics only — gas prices, elections, culture, crypto and golf — flags every contract-price move of $0.10 or more, publishes each flag to a pair of live scrolling feeds, follows every market until it resolves YES or NO, and runs four simulated strategies against the same signals so the results can be compared instead of assumed.

The five topics

Topic membership is decided by an explicit, auditable rule set (series prefix, then category, then keyword). A market that matches no rule is left out rather than guessed into a topic.
