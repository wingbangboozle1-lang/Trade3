K3 API Keys · 6 claims
  • API keys are asymmetric key pairs; private key signs, registered public key verifies
  • Ed25519 (recommended, RFC 8032, 64-byte signature) and RSA 2048-bit (RSA-PSS, SHA-256, MGF1-SHA256, salt length = digest length) are supported
  • Headers: KALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP (ms), KALSHI-ACCESS-SIGNATURE (base64)
  • Signature = base64(sign(timestamp + METHOD + path_without_query))
  • Timestamp must be within 30 seconds of Kalshi's clock or the request returns 401 header_timestamp_expired
  • Private key cannot be retrieved again after the key is created

K4 Rate Limits and Tiers · 5 claims
  • Token-bucket limits; most requests cost 10 tokens
  • Separate Read and Write buckets
  • 429 returns error code too_many_requests; back off exponentially
  • GET /portfolio/balance uses its own bucket: 1/sec on Basic/Advanced, 5/sec above
  • Balance only changes on fills, settlements and transfers; prefer the fills WebSocket channel over polling

K5 Orderbook Responses · 6 claims
  • GET /markets/{ticker}/orderbook returns orderbook_fp with yes_dollars and no_dollars arrays
  • Each level is [price_dollars, count_fp]; arrays are ascending, so the best bid is the last element
  • Order counts per level are not returned (one entry per price level, aggregated size)
  • Only bids are returned; YES bid at X equals NO ask at 1-X
  • Best YES ask = 1 - best NO bid; best NO ask = 1 - best YES bid
  • Unknown ticker returns 200 with empty arrays, not 404

K6 Kalshi Fee Schedule (PDF, effective July 7, 2026) · 6 claims
  • General trading (taker) fee: fees = roundup(M * 0.07 * C * P * (1-P))
  • Maker fee: fees = roundup(M * 0.0175 * C * P * (1-P)); maker multiplier M defaults to 0 for the general schedule
  • Trading fees are only charged for orders immediately matched against resting orders, unless the series has maker fees
  • round up means the fee plus position cost is rounded up to a centicent ($0.0001)
  • There is no settlement fee
  • Per-series taker/maker multipliers are listed in the Non-Standard Fees table; 1 means one times the general formula

K7 Fee Rounding · 3 claims
  • Trade fee is rounded up to the nearest $0.000001 (six decimals)

  • Net fee = trade fee + rounding fee - rebate, always >= $0

K8 Quick Start: WebSockets · 6 claims
  • WebSocket connections are authenticated during the handshake with the same three headers
