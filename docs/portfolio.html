How to run the full backtest locally (Python)

The repo includes kalshi_client.py, strategies.py, backtest.py and run_sim.py. The Python backtest replays price snapshots and settles against Kalshi result fields, categorizing every trade by topic and strategy.

pip install -r requirements.txt
python run_sim.py --base demo --polls 12 --interval 30 --strategy momentum
# writes sim_output.json (alerts + portfolio + trades)

Live demo execution (real demo orders) requires KALSHI_API_KEY_ID + KALSHI_PRIVATE_KEY_PATH from demo.kalshi.co → Account & security → API Keys. Signing follows Kalshi's authenticated-requests guide. Keys are never committed or sent anywhere except Kalshi.
