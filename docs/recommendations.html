How to make this more live and interactive

You asked for suggestions. Each one below is tied to something that actually exists in Kalshi's API or documentation, verified during this build — no hand-waving, and no feature that the API cannot support. They are ordered by how much they change the experience for the effort involved.

The single biggest upgrade. Today the dashboard polls REST every 15 seconds because that is the only path available from the build sandbox. Switching to the authenticated WebSocket changes the feel of the whole product: alerts would land in milliseconds instead of on a 15-second tick, and the chat would scroll like a real trading terminal.

Interaction ideas that cost almost nothing

  • Pin a market. Clicking a market already opens the drawer; pinning it keeps the chart and depth pinned while you watch the feeds around it.
  • Threshold slider. The $0.10 rule is the brief, but letting a trader tighten it to $0.20 instantly answers “what actually moves on this venue?” without changing the underlying engine.
  • Sparklines in the table. A 20-pixel line per row makes a 200-row table scannable by shape instead of by reading numbers.
  • Keyboard-first review. Arrow keys to step through alerts and space to open the drawer turns triage into a two-minute pass.
  • Sound cue on threshold crossings only. A single diagnostic click for a $0.10 break is useful; sound on every tick is noise and gets muted within a minute.
  • Copyable deep links. Every filter state should be in the URL so a trader can paste “crypto, up-only, last hour” into a chat.

What I would deliberately not build

  • Automatic news attribution without a licensed feed. Guessing that a headline caused a jump is fabrication. It needs timestamped news with an explicit confidence method, which is what recommendation 4 describes.
  • A “prediction accuracy” scoreboard for the demo account. Demo prices are not real prices, so publishing an accuracy record from them would mislead.
  • Any auto-trading against production. Order endpoints exist and are implemented, but nothing in the simulator touches them, and the default is off.
