Definitions & heuristics (explicit, auditable)

  • $ volume = volume_fp × last_price_dollars. Kalshi exposes contract counts and prices separately; this is the documented ranking approximation. Raw volume_fp is shown alongside.
  • Alert: |current − previous poll price| ≥ $0.10 for the same ticker.
  • High-ROI filter: price ∈ [$0.15, $0.85], $ volume ≥ topic median, spread ≤ $0.10, |move| ≥ $0.05. Research heuristic only — not a model, not advice.
  • Strategies: momentum / mean-reversion / favorite-longshot / volume-breakout (see strategies.py). Paper fills at quoted ask; settlement at $1/$0 via Kalshi result.
  • Charts: x = time, y = contract price ($0–$1). Windows: 60s / 5m / 1h / 24h. Candlesticks: period_interval 1 (min), 60 (hour), 1440 (day).
  • WebSocket: requires API-key handshake (timestamp + "GET" + "/trade-api/ws/v2" signed). The site defaults to REST polling so it works with zero setup; WS is an optional upgrade with user keys. See Quick Start: WebSockets.
  • Auth signing (Python client): RSA-PSS/SHA-256 or Ed25519 over timestamp + METHOD + path (no query string), base64-encoded. See Authenticated Requests.
