Kalshi live dashboard — highest-dollar events, swing alerts, charts & simulated trading

Tracks gas prices, elections, culture, crypto and golf only on the Kalshi demo environment. Live prices come from the public Kalshi Trade API (no key needed for market data). Alerts fire on any contract-price swing ≥ $0.10 in either direction.

LIVE Demo: external-api.demo.kalshi.co No manual input required

1 · Two alert chats

All ≥ $0.10 swings scroll in the main chat. A second chat shows only high-ROI-filtered events (transparent heuristic — see Methodology).

2 · Charts + liquidity

Price-over-time graph (seconds / minutes / hours windows), order-book depth (contracts available at each price), and resolution tracking until each event settles yes/no.

3 · Simulated trading

Paper trades open automatically on high-ROI alerts. Portfolio page categorizes results by topic and strategy. Real demo orders need your own demo API keys (never stored here).

Executive summary

What this is. A static GitHub Pages site that reads Kalshi's public Trade API v2 in the browser and turns it into a trader's decision dashboard for five topics. No backend, no keys, no manual input — open the dashboard and it polls live data.

How topics map to Kalshi (verified 2026-11-20). Kalshi organizes markets as Series → Events → Markets. Gas = Economics + Oil & Gas (e.g. KXAAAGASM, settled by AAA). Elections = Elections. Culture = Entertainment (Kalshi has no “Culture” category — flagged). Crypto = Crypto. Golf = Sports + Golf tag. Full table with source links: Methodology.

“Highest dollar amount”. Kalshi has no single dollar-volume field, so events are ranked by volume_fp × last_price_dollars (documented approximation). Raw contract volume is shown alongside.

Alerts. Every poll compares each contract's last price to its previous poll; |Δ| ≥ $0.10 posts to the all-events chat. The high-ROI chat adds: price $0.15–$0.85, dollar volume above topic median, spread ≤ $0.10, |move| ≥ $0.05. Heuristic, not advice.

Charts & liquidity. Canvas price chart with 60s / 5m / 1h / 24h windows, backfilled from Kalshi candlesticks (1-min bars) plus live poll points. Order-book panel shows YES/NO bids with contract counts per price level.

Resolutions. Settled markets are polled separately and listed with their result (yes/no) and settlement time. Paper trades settle against that result.

Trading. Default is fully simulated (localStorage). To execute on the Kalshi demo account, add your demo API key + private key locally (Python client provided; browser WS optional). See Portfolio and Methodology.

News/catalysts. The Kalshi API does not provide news. The dashboard links each market to its official settlement source (e.g. AAA gas prices) and API record — it never invents a cause for a jump. Causal attribution is flagged as unverified.
