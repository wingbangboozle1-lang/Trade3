Executive summary

The five findings that mattered most

Live markets, by topic

Each row is a real market read from the demo Trade API. The source column links to the exact endpoint that returned it. Values the API did not return are blank and marked — unverified rather than filled in.

Topics

Topics are kept separate, and markets inside a topic are grouped together. Each topic page explains exactly how markets are routed into it, using Kalshi's own metadata rather than guesswork.

How the dashboard behaves

Swing alerts (≥ $0.10)

A move counts when the absolute price change is greater than or equal to $0.10, in either direction. Comparisons happen in integer 1/10,000-dollar units, so a move of exactly ten cents can never fail to fire through floating-point rounding. Two bases are reported separately: tick (change since the previous poll) and day (change against Kalshi's own previous_price_dollars, documented as the last traded YES price a day ago).

Two scrolling chats

The dashboard shows two feeds side by side. All swings is every qualifying move. Model's high-ROI picks only shows swings that clear a score of 45, and each pick prints its own inputs — edge per contract, fee, spread cost — so the ranking is auditable instead of a black box.

Charts and liquidity

Click any market for a chart with time on the X axis and contract price on the Y axis, switchable between seconds, minutes and hours. Underneath it, the order book shows how many contracts rest at each price, in contracts and in dollars. Kalshi returns bids only, so the YES ask is derived as 1.00 − best NO bid — exactly as the official order book page specifies.

Resolution and strategies

Markets are tracked until Kalshi reports a result, and the result (yes or no) is recorded once with its source. Simulated trades open on high-ROI alerts across four documented strategies, then exit on take-profit, stop-loss, market close or official settlement — and the results are grouped by strategy type so you can see which style of trade actually worked.

Read this before using any number here.

Kalshi's own documentation states that "the price and behavior of markets in the demo environment may not be reflective of those in real markets." Every price on this site is a demo price. Several demo markets sit at $0.00 with empty order books, so swing alerts on the demo environment are naturally sparse. Nothing here is investment advice, and the simulated results are a test harness, not a track record.
