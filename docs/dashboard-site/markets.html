Tracked markets

The full set of markets captured from the Kalshi demo Trade API, sorted by 24-hour volume. Every row carries a direct link to the official endpoint that returned it, plus the settlement source Kalshi publishes for that series. Untracked topics are not mixed in.

How to read the empty cells. A dash marked — unverified means the official API did not return that field for that market at capture time. It is never an estimate, and it is never filled in from another market.

Series metadata behind the topic routing

Topic routing uses Kalshi's own series metadata, not guesswork. This table is the raw evidence: for each series, the category, tags and product_metadata.scope values that the API returns.

Each series row links to GET /series/{ticker}. The Get Series List documentation explains that the category filter matches any entry in a series' categories list, which is why one series can appear under more than one discovery category.
