Kalshi demo dashboard

A source-audited dashboard and findings site for the Kalshi demo Trade API, covering five topics only — gas prices, elections, culture, crypto and golf — with $0.10 swing alerts, dual alert feeds, interactive charts, order-book liquidity, yes/no resolution tracking and simulated strategy trading.

4. Risks and limits

  • Demo ≠ production. Kalshi's own words: the demo “may not be reflective of those in real markets”. Prices, liquidity and therefore alert frequency will differ materially in production.
  • Sandbox egress. The build sandbox cannot reach Kalshi's hosts at all (TLS is reset), so the live app was verified with a fake client plus fixtures, and every published value was read through a separate page-fetch path that does reach the API. On a normal network the app talks to Kalshi directly.
  • Demo liquidity. Many demo markets are quoted at $0.00 with empty books, so the alert feed can legitimately sit empty. That is reported as empty, never padded.
  • Strategy results are not a track record. The simulator assumes fills at modelled prices and one position per market; both are simplifying assumptions.
  • Portfolio read needs your key. Without KALSHI_API_KEY_ID and a private key the portfolio panel states plainly that it is not connected.

5. Open items published for review

Eight items are published on the Flagged for Review page rather than being quietly resolved. Two are high severity: the missing Gas/Golf categories, and the demo price caveat.

6. Running it

# 1. Start the collector + dashboard (zero dependencies, Node 20+)
npm start
#    dashboard: http://localhost:3000/app/
#    this site: http://localhost:3000/
#    API:       http://localhost:3000/api/state

# 2. Optional: read the real Kalshi demo portfolio (read-only)
export KALSHI_API_KEY_ID="your-demo-key-id"
export KALSHI_PRIVATE_KEY_PATH="./kalshi-demo-key.pem"
npm start

# 3. Verify everything offline
node tests/smoke-test.js

# 4. Check this published site for broken links
node scripts/check-links.js

Keys are created in the Kalshi demo UI under Account & Settings → API Keys. Demo keys never work against production and production keys never work against demo — official docs ↗. This project never asks for, stores or transmits your private key anywhere except to Kalshi, signed locally.

7. Bottom line

The dashboard does what was asked, and it is honest about the two things that could not be finished as originally framed: automatic news attribution, which needs a licensed feed to do without inventing causes, and GitHub Pages enablement, which this session's token cannot switch on. Both are published with the exact evidence so you can decide what to do next.
