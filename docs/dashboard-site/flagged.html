Flagged for Review

These are the irregularities, surprises and open questions found while building this. Nothing here is hidden or silently resolved: each item states what was found, the exact evidence, and a link so you can verify it yourself. Nothing on this page blocks the site from working.

How to use this page. Items marked high change how you should read the rest of the site. Items marked medium are judgement calls you may want to overrule. low items are recorded so nobody rediscovers them later.

Flagged by the other session's build (kept, not discarded)

A parallel session shipped its own dashboard in this repository before this build was integrated (its Flagged page). Its seven open items are reproduced below, unedited in substance, so a reviewer sees one consolidated list. Several overlap with items above; where they disagree, this page notes it.

One correction, recorded rather than silently dropped. That build flags “Kalshi has no Culture category” and maps Culture to Entertainment as a proxy. That is not accurate as of this capture: GET /series?category=Culture returns real series with "category":"Culture" (for example KXXBANNEDGROK and KXXBANNEDMURRAYHILLGUY1). Culture is therefore used directly as a category here, with no proxy. The genuinely empty case is different: the Culture series had no open markets at capture time. Verify ↗

What is not flagged, and why

  • Empty alert feeds. Not an error. Demo markets are frequently quoted at $0.00 with empty order books, so no $0.10 move is possible. The dashboard reports its data mode instead of faking activity.
  • Blank cells in tables. These are fields the API did not return. They are rendered as — unverified rather than guessed, which is the verification rule you asked for.
  • Small or zero trade counts. The simulator only opens a position when an alert clears the score threshold, so a quiet demo produces few trades. Reporting zero is correct.

Items you may want to overrule

  • The high-ROI score threshold of 45 is a judgement call, not a Kalshi number. It is exposed as one constant so it can be tuned without touching anything else.
  • The five-topic routing rules are documented in priority order; if you would rather route anything tagged Oil & Gas more broadly, that is a one-line change in server/topics.js.
  • The four strategies were chosen to be distinguishable rather than exhaustive — momentum, mean reversion, threshold break and fade-extreme. Adding a fifth is deliberately trivial.
